# 🎬 人生弹幕机

> 把你的聊天记录、日记、深夜碎碎念，变成别人眼里的你。

你发过的微信、写过的日记、半夜在朋友圈发的仅自己可见——这些文字里藏着一个你自己都不知道的人。

人生弹幕机做的事情很简单：**你扔进来一段文字，它还你一场关于你自己的电影。**

---

## 它会给你什么？

| 模块 | 是什么 | 像什么 |
|------|--------|--------|
| 🎬 人生弹幕 | AI 生成的海量弹幕飘过屏幕 | B 站观众在围观你的人生 |
| 💜 给此刻的你 | 精神状态诊断，但不说人话 | 一个很懂你的朋友写的便签 |
| ☁️ 人设词云 | 从你的文字里提炼关键词 | 别人眼中的你的标签云 |
| 🎥 如果你是电影角色 | 把你的生活拍成一部电影 | 王家卫或者新海诚的剧本卡 |

---

## 怎么玩

1. 打开页面，粘贴一段聊天记录 / 日记 / 朋友圈 / 纯发疯文字
2. 选择分析模式：**免费基础分析**（浏览器本地跑）或 **深度分析**（用自己的 API Key）
3. 点「开始分析」，喝口水
4. 你会看到弹幕飘过 → 情绪被读懂 → 关键词被提炼 → 最后得到一张电影剧照

不想打字？点范例直接看效果。深夜不想打字？按麦克风说话。

---

## 自己跑起来

```bash
# 前端
cd client && npm install && npm run dev

# 后端（可选，演示模式需要）
cd server && npm install && npm run dev
```

前端默认跑在 `http://localhost:5173`，后端 `http://localhost:3001`。

深度分析需要自己的 API Key，支持 DeepSeek / OpenAI / Anthropic。推荐 DeepSeek，国内直连，便宜。

---

React 19 + Vite + Tailwind CSS + Framer Motion + Zustand + Transformers.js + Web Speech API
