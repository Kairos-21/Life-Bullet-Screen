# 🎬 人生弹幕机

> 你的文字里，藏着另一个自己。

---

你有没有在深夜翻过自己的聊天记录？

那些加班后的「晚安」、日记里没写完的句子、朋友圈仅自己可见的碎碎念——你以为是日常的边角料，其实拼起来，就是一张你从未见过的自画像。

**人生弹幕机**做的事情很简单：你扔进来一段文字，它还你一场关于你自己的电影。

---

## 它会给你什么

**🎬 人生弹幕**

弹幕从屏幕上飘过，像一群素未谋面的观众在围观你的人生。有时候戏谑，有时候温柔，有时候一句话戳中你——「这条弹幕谁发的，怎么比我自己还懂我」。

**💜 给此刻的你**

不是冷冰冰的诊断报告。它更像一个深夜里愿意听你说话的朋友，看完你的文字之后，在便签上写了几句话递给你。没有打分，没有评判，只有一个比喻和一句悄悄话。

**☁️ 人设词云**

从你说过的话里，提炼出那些反复出现的词。它们是你最近生活的关键词。有时候，那些你从来没有提过的词，比你说出口的更有意思。

**🎥 如果你是电影角色**

把你的生活拍成一部电影。有一个片种，一首 BGM，一组色调，和一句属于你的台词。这可能是整场分析里最浪漫的部分——你的人生，原来是可以被拍成电影的。

---

## 怎么用

打开页面，把你想说的话扔进去。可以是：

- 一段深夜的微信聊天
- 几篇写了没发出去的日记
- 朋友圈的截图文字
- 或者什么都不想，对着麦克风说出来

然后点一下按钮，喝口水，等一小会儿。你会看到一群弹幕飘过来，然后是一张写给你的便签，然后是那些反复出现在你生活里的词，最后——你的生活变成了一张电影剧照。

也可以先点范例看看效果，不用自己写一个字。

---

## 跑起来

```bash
# 前端
cd client && npm install && npm run dev

# 后端（演示模式需要）
cd server && npm install && npm run dev
```

前端 `http://localhost:5173`，后端 `http://localhost:3001`。

深度分析需要 API Key，支持 DeepSeek / OpenAI / Anthropic。

---

## 技术栈

React 19 · Vite · Tailwind CSS · Framer Motion · Zustand · Transformers.js · Web Speech API

---
