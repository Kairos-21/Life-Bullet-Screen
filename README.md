# 🎬 人生弹幕机

> 不是每一种念头，都要发送给全世界。  
> 但它们也许值得被看见一次。

人生弹幕机是一个关于「碎片化表达」的 AI 实验。

它试图接住那些散落在聊天记录、日记、朋友圈草稿和深夜自言自语里的句子，并把它们转化成一场关于你自己的弹幕电影。

你输入一段文字，它会生成：

- 三幕式人生弹幕
- 写给此刻的你的一段旁白
- 从文字中提炼出的人设词云
- 一张"如果你是电影角色"的情绪画像
- 一句安静收尾的终幕文案

它不是诊断报告，也不是性格测试。

更像是一个表达实验：

**AI 能不能先接住人的碎片，而不是急着分析它？**

---

## ✨ 它会给你什么

### 🎬 人生弹幕

你的文字会被转化成三幕弹幕。

第一幕慢慢靠近，像有人试探着读懂你；  
第二幕逐渐变密，情绪和关键词开始浮现；  
第三幕慢慢散开，像一场放映结束后，观众轻轻离场。

弹幕里可能有调侃，也可能有安静的共鸣。  
它不替你下结论，只试着把那些散落的情绪重新摆到你面前。

---

### 💜 给此刻的你

这不是冷冰冰的分析结果。

它更像一张写给你的便签：  
读完你的文字后，留下一个比喻、几句旁白，和一点温柔的回应。

没有打分。  
没有评判。  
也不急着告诉你该怎么办。

---

### ☁️ 人设词云

系统会从你的文字里提炼出一些反复出现的词。

它们可能是你最近生活里的关键词，也可能是一些你没有意识到、却一直藏在表达里的线索。

有时候，词云不一定准确概括你。  
但它会提供一个重新观察自己的角度。

---

### 🎥 如果你是电影角色

如果把你此刻的状态拍成一部电影，它会是什么类型？

人生弹幕机会生成：

- 片种
- BGM 气质
- 画面色调
- 一句属于你的台词

这是整个体验里更浪漫的一部分。  
它不是在定义你，而是把你的情绪临时放进一帧电影画面里。

---

### 🌅 终幕

所有内容播放结束后，屏幕会安静下来。

系统会根据你文字里的情绪，留下一句收尾的话。

它不是总结，也不是建议。  
更像一个朋友听完你的故事后，沉默了一会儿，然后说出的那一句。

---

## 🕹️ 怎么使用

打开页面，把你想说的话放进去。

可以是：

- 一段深夜的微信聊天
- 几句没写完的日记
- 朋友圈仅自己可见的碎碎念
- 一段随手打下来的情绪记录
- 或者直接对着麦克风说出来

然后点击按钮，等一小会儿。

弹幕会分三幕出现，随后是一张写给你的便签、一组人设词云、一段电影角色画像，最后以一句终幕文案收束。

你也可以先点击范例，直接体验完整流程。

## 🚀 本地运行

### 前端

```bash
cd client
npm install
npm run dev
```

### 后端

```bash
cd server
npm install
npm run dev
```

默认地址：

- 前端：http://localhost:5173
- 后端：http://localhost:3001

## 🔑 API Key 说明

深度分析模式需要配置 API Key。

当前支持：

- DeepSeek
- OpenAI
- Anthropic

如果没有 API Key，也可以使用演示模式。
演示模式会调用预置示例数据，可以体验完整流程。
